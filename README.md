# Gestor Contable

Es un programa que te ayuda a registrar y ordenar tus facturas y gastos.

## Funcionalidades

- Vas a poder registrar los datos de tus facturas y gastos, seleccionar el estado de la factura (Ventas o Compras) y lo vas a poder actualizar (Cobranza o Pagos) cuando lo necesites.

## Entidades

- Las entidades que vas a poder registrar son el monto, la fecha, el comprobante, el nombre del cliente o proveedor y el estado (Ventas/Cobranza, compras/pagos y gastos).

## Resumen financiero

- Al final del registro el programa va a mostrarte los totales (Ventas, Cobranza, compras, pagos y gastos) y un balance.
